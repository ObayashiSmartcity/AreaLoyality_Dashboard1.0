# 命令

添付されたMarkdownファイル（以下「mdファイル」）の内容を理解したうえで、mdファイル内の「項目4」に該当するデータリストを作成してください。

# 競合都市

以下の都市を比較対象としてください。

- 飛騨市：ファンコミュニティの観点
- 金沢市：北陸エリアにおける直接競合の観点
- 松本市：自然環境および二拠点居住の観点
- 宇都宮市：MRT・コンパクトシティの観点

# 出力カラム

以下の順序で出力してください。

1. AreaCode
2. AreaName
3. IndexCode
4. IndexName
5. IndexValue
6. IndexValueNorm
7. Source
8. SourceURL
9. SourceYear
10. Evaluation

# 各カラムの入力要件

## AreaCode
対象都市を識別するコードを入力してください。
原則として全国地方公共団体コードを使用してください。

## AreaName
対象都市名を入力してください。

## IndexCode
mdファイルの項目4で定義されている各指標を識別するコードを入力してください。
コード定義が存在しない場合は、一意となるコードを採番してください。

## IndexName
mdファイルの項目4で定義されている指標名を入力してください。

## IndexValue
各指標について、実際に収集または算定した数値を入力してください。

- 数値として出力すること
- 単位はEvaluationに明記すること
- 推計値を使用する場合はEvaluationに明記すること

## IndexValueNorm
競合都市間でIndexValueを正規化した数値を入力してください。

- 同一指標内で比較すること
- 正規化方法はEvaluationに明記すること
- 値の範囲は原則0～100とする
- 指標の方向性（大きいほど良い／小さいほど良い）を明記すること

## Source
IndexValue算出の直接根拠となる資料名・統計名・データセット名を入力してください。

例：
- e-Stat 国勢調査
- RESAS 人口動態データ
- 総務省住民基本台帳人口移動報告
- 市公式統計年鑑

単なる出典区分ではなく、使用した資料名を記載してください。

## SourceURL
Sourceに対応する参照URLを入力してください。

- 可能な限り一次情報のURLを使用すること
- URLが取得できない場合は「N/A」と記載すること

## SourceYear
使用したデータの対象年度を入力してください。

例：
- 2023
- 2024
- FY2023

複数年度を組み合わせた場合はEvaluationに記載してください。

## Evaluation
算定方法および評価方法を記載してください。

以下を含めてください。

- IndexValueの算定式
- 使用した元データ
- 単位
- 正規化手法
- 正規化対象都市
- 指標の評価方向（高いほど良い／低いほど良い）
- 推計・補完・推論を行った場合の内容
- 欠損値処理方法
- 年度差異の調整方法

推論や推計を含む場合は、事実データと推論部分を明確に区別してください。

# データ作成ルール

- mdファイルの項目4に定義された全指標を対象とすること
- 全競合都市について同一定義で比較可能なデータを収集すること
- 原則として同一年度のデータを使用すること
- 同一年度が取得できない場合は直近年度を利用し、その理由をEvaluationへ記載すること
- 都市ごとに定義が異なる統計を使用する場合は差異を明示すること
- 算出根拠のない数値は作成しないこと
- 推計値を使用する場合は推計であることを明示すること
- Source・SourceURL・Evaluationのみを参照しても再現可能なレベルで記述すること
- 最終出力前に元データ・算定結果・正規化結果の整合性を確認すること

# 正規化ルール

特段の指定がない場合はMin-Max正規化を使用すること。

正方向指標（値が大きいほど評価が高い）

IndexValueNorm =
((IndexValue - MinValue) / (MaxValue - MinValue)) × 100

逆方向指標（値が小さいほど評価が高い）

IndexValueNorm =
((MaxValue - IndexValue) / (MaxValue - MinValue)) × 100

使用した方式はEvaluationに記載すること。

# 出力形式

CSV形式または表形式で出力すること。

1レコードは「1都市 × 1指標」とする。

カラム順は以下で固定すること。

AreaCode,
AreaName,
IndexCode,
IndexName,
IndexValue,
IndexValueNorm,
Source,
SourceURL,
SourceYear,
Evaluation
