# 関係人口増加に効く都市要素の検討
## 〜自然・文化／空間レイヤーに絞った必要データの整理〜

作成日：2026年8月31日

---

## 0. 検討の前提

- **ゴール**：関係人口の増加
- **定義**：関係人口の増加 ＝ 地域ロイヤリティの上位レイヤーと同義
- **論点**：関係人口増加に効く都市要素は何か
- **スコープ限定の理由**：
  - 「活動レイヤー」「機能レイヤー」は可変であり、当社の介入施策（イベント、スタンプラリー、整備等）で対策可能
  - そのため、これらは「効果検証すべき施策変数」であって「説明変数」としては不向き
  - 一方、「自然・文化レイヤー」「空間レイヤー」はその街固有で変数となりづらいため、**「どんな街なら関係人口が育ちやすいか」を説明する変数**として優先的に評価すべき

| レイヤー | 性質 | 位置づけ |
|---|---|---|
| 活動 | 可変・介入可能 | 施策変数（結果に対する打ち手） |
| 機能 | 可変・介入可能 | 施策変数（結果に対する打ち手） |
| **自然・文化** | **固有・変数となりづらい** | **説明変数（今回の優先評価対象）** |
| **空間** | **固有・変数となりづらい** | **説明変数（今回の優先評価対象）** |

---

## 1. 仮説：関係人口を生む条件

関係人口は、「場所への愛着」だけでなく、**「自分がその街に居場所を持てる感覚」**から生まれると仮定する。

すると効くのは、

- ~~景観資源~~ そのものではなく
- **景観・文化資源が「関係資源」（人とのつながり、記憶、語りたくなる体験）を生みやすい環境かどうか**

である。

この仮説に基づき、自然・文化／空間レイヤーを以下の**4つの因子領域**に再編して評価する。

---

## 2. 4つの因子領域と必要データ

### ① 地域アイデンティティ資源（その街らしさ）

**なぜ効くか**：関係人口になる人は「どこでもいい」ではなく「その街だから関わる」状態になる。富山なら富山にしかない固有性が、関わり続ける理由（物語）の土台になる。

| 必要データ項目 |
|---|
| 歴史文化資源数 |
| 指定文化財数（国宝・重要文化財等） |
| 神社仏閣数 |
| 歴史的建造物数 |
| 伝統行事数 |
| 祭礼開催頻度 |
| 郷土芸能数 |
| 景観重点地区面積 |
| 地名継承率 |

---

### ② 記憶形成資源（景観・記憶）

**なぜ効くか**：愛着形成研究では、接触回数よりも「記憶に残る体験」が重要とされる。人は施設を覚えるのではなく、風景を覚える。富山であれば「立山連峰」「松川」「環水公園」「城址公園」といった景観要素がこれに当たる。

| 必要データ項目 |
|---|
| 水辺面積 |
| 河川アクセス性 |
| 公園面積 |
| 緑被率 |
| 山岳眺望地点数 |
| ランドマーク数 |
| 夜景スポット数 |
| 景観多様性指数 |

---

### ③ 偶発交流が起こりやすい空間構造（滞留空間）

**なぜ効くか**：関係人口は施設によってではなく、人との接触によって深まる。飛騨市の関係人口調査でも「現地の知人・友人の存在」が愛着に強く影響することが確認されている。したがって「人が滞在できる場所の量」を測るべきである。

| 必要データ項目 |
|---|
| 公共広場面積 |
| オープンスペース面積 |
| 歩行者専用空間 |
| Waterfront（水辺）滞留空間 |
| ベンチ密度 |
| カフェ密度 |
| 回遊歩行ネットワーク長 |
| 地上歩行率 |

---

### ④ 回遊しやすい都市構造（回遊性）

**なぜ効くか**：MACHIMEGURIの文脈で特に重要。関係人口形成には「体験の連鎖」が必要であり、1回の訪問で1箇所だけ見る街より、5〜6箇所を自然に巡れる街の方が愛着形成の機会が増える。

| 必要データ項目 |
|---|
| 駅から主要拠点までの徒歩時間 |
| 回遊ルート密度 |
| スポット間平均距離 |
| 公共交通アクセス指数 |
| 歩行者流動量 |
| 自転車利用環境 |
| TOD（公共交通指向型開発）指標 |

## 3. 新規に追加すべき合成指数（提案）

既存の環境データリストの個別指標に加え、関係人口分析専用として以下の**合成指数**を新設することを提案する。

| 合成指数名 | 構成要素 |
|---|---|
| **① 景観固有性指数** | 山が見える／水辺がある／歴史景観がある／シンボル建築がある |
| **② アイデンティティ指数** | 文化財密度／祭り密度／歴史施設密度／地域ブランド数 |
| **③ 滞留可能性指数** | ベンチ／広場／公園／Waterfront／カフェ |
| **④ 回遊性指数** | 交差点密度／歩行ネットワーク／公共交通／スポット集積度 |
| **⑤ Narrative Asset Index（語り資産指数）** | 景観資源／文化資源／シンボル資源／フォトスポット の合成 |

### ⑤ Narrative Asset Index（語り資産指数）について

関係人口になる前段には「誰かに紹介したい」という心理状態がある。これは最終的に最も説明力が高い変数になると想定される。景観・文化・シンボル・フォトスポットといった資源を統合し、「思わず語りたくなる度」を定量化する指数として新設する価値がある。

## 4. まとめ

| 因子領域 | 測るもの | 富山中心市街地における該当例（仮説） |
|---|---|---|
| ① アイデンティティ資源 | その街固有の文化・歴史 | 富山城址公園、日枝神社、池田屋安兵衛商店 等 |
| ② 記憶形成資源 | 記憶に残る景観 | 立山連峰の眺望、富岩運河環水公園、松川 |
| ③ 滞留空間 | 人と接触できる場 | ブールバール広場、環水テラス、SOGAWA BASE |
| ④ 回遊構造 | 体験の連鎖のしやすさ | 富山駅〜城址公園〜総曲輪の回遊動線、LRT |

**結論**：
関係人口を説明するための自然・文化・空間レイヤーは、「何があるか（資源の有無・量）」よりも、**「愛着と人間関係を生みやすい場かどうか」を測る方向に再編すべき**である。

最も説明力が高いと想定される因子は、
1. アイデンティティ資源
2. 景観・記憶資源
3. 滞留空間
4. 回遊構造

の4因子であり、特に富山中心市街地においては「立山眺望」「水辺」「歩行回遊」「公共空間」の説明力が高いという仮説を置く。MACHIMEGURIウィークの投稿・スタンプ取得データが蓄積されれば、これら4因子との相関を実証的に検証できると考えられる。
